# 🎨 얼굴 그리기 대회 (워크샵용)

QR 하나로 참여하는 모바일 얼굴 그리기 게임입니다. 앱 설치나 로그인 없이 참여할 수 있고, 모두 무료 플랜으로 운영할 수 있어요.

| 파일 | 역할 |
|---|---|
| `host.html` | 진행자 화면(빔프로젝터·대형 스크린용) |
| `index.html` | 참가자 휴대폰 화면(QR로 접속) |
| `shared.js`, `shared.css` | 공통 코드 |
| `firebase-config.js` | **여기에 Firebase 설정을 붙여넣어요** |
| `database.rules.json` | Firebase 보안 규칙(복사해서 콘솔에 붙여넣기) |

---

## 0. 먼저 맛보기 (설정 없이 1분)

설정 전에는 자동으로 **데모 모드**로 돌아가요. 같은 브라우저의 탭끼리만 연결됩니다.

1. 아래 3단계(GitHub Pages)로 올린 뒤 `host.html`을 열어요. 로컬에서 보려면 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000/host.html`을 열면 돼요.
2. 진행자 화면에 있는 참가 링크를 **새 탭**으로 2~3개 열어요. 탭마다 다른 참가자로 들어가요.
3. ⚙️ → "🧪 테스트 참가자 5명 추가"로 인원을 채워 전체 흐름을 볼 수 있어요.

---

## 1. Firebase 실시간 DB 만들기 (무료, 약 7분)

1. https://console.firebase.google.com 에 접속해 **프로젝트 추가**를 눌러요. 이름은 예를 들어 `face-game`으로 하고, Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴에서 **빌드 → Realtime Database → 데이터베이스 만들기**를 눌러요.
   - 위치: **싱가포르(asia-southeast1)**. 한국에서 가장 가까워요.
   - 보안 규칙: **테스트 모드로 시작**
3. 생성된 DB의 **규칙** 탭에서 내용을 `database.rules.json`의 내용으로 바꾸고 **게시**를 눌러요.
4. 프로젝트 개요 옆 ⚙️ → **프로젝트 설정** → 아래쪽 "내 앱"에서 **웹(</>)** 아이콘을 눌러 앱을 등록해요. Hosting 체크는 필요 없어요.
5. 화면에 나온 `firebaseConfig = { ... }` 값을 `firebase-config.js`에 그대로 붙여넣어요.
   - **`databaseURL`이 꼭 있어야 해요.** 없으면 Realtime Database 화면 상단의 `https://....firebasedatabase.app` 주소를 직접 넣어주세요.

> 무료(Spark) 플랜은 동시 접속 100명, 저장 1GB, 월 다운로드 10GB까지예요. 20명 워크샵에는 충분해요.

## 2. Gemini API 키 받기 (무료, 약 3분)

1. https://aistudio.google.com/apikey 에 접속해 **API 키 만들기**를 눌러요.
2. 키(`AIza...`)를 복사해 두세요.
3. 키는 GitHub에 올리지 **않아요**. 행사 당일 진행자 화면의 ⚙️ 설정에 붙여넣으면, 그 컴퓨터 브라우저에만 저장돼요.
4. 설정에서 **API 키 테스트**를 눌러 ✅가 뜨는지 확인하세요. 모델은 `auto`로 두면 사용 가능한 최신 Flash 모델을 자동으로 골라요.

> 참고: Gemini 무료 등급은 입력 내용(그림, 이름, 한 줄 설명)이 Google 제품 개선에 쓰일 수 있어요. 민감하다면 결제 계정을 연결하세요. 20명 1회 심사는 비용이 몇 원 수준이에요.

## 3. GitHub Pages에 올리기 (무료, 약 5분)

1. https://github.com/new 에서 새 저장소를 만들어요. 예: `face-game`, **Public**.
2. 저장소 화면에서 **Add file → Upload files**를 누르고 이 폴더의 파일을 전부 드래그해서 **Commit changes**를 눌러요.
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `/(root)` → **Save**
4. 1~2분 뒤 접속해요.
   - 진행자 화면: `https://<내아이디>.github.io/face-game/host.html`
   - 참가자 화면은 진행자 화면의 QR에 자동으로 들어가요.

> `firebase-config.js`를 나중에 고쳤다면 같은 방법으로 다시 업로드하면 돼요. 반영까지 1분 정도 걸려요.

## 행사 당일 진행 순서

1. 노트북을 빔프로젝터에 연결하고 **Chrome으로 `host.html`을 연 다음 F11(전체 화면)**을 눌러요.
2. ⚙️ 설정에서 **주제**(예: "옆자리 동료 얼굴", "10년 후 내 모습"), **그리기 시간**(기본 5분), **Gemini 키**를 확인해요.
3. 참가자가 QR을 찍고 이름을 입력하면, 이름표 단 빈 얼굴이 화면에서 통통 튀어다녀요.
4. **그리기 시작 ▶**을 누르면 타이머가 시작돼요.
   - 오른쪽 위 카드에 지금 그리고 있는 얼굴이 3.5초마다 랜덤으로 바뀌어 보여요.
   - 제출한 아바타는 몸통 이름표와 함께 튀어다니고, 포인트 한 줄이 말풍선으로 나와요.
   - 제출한 사람은 휴대폰에서 다른 사람 그림에 ❤️를 누를 수 있어요(최종 점수 30%).
5. **마감 & AI 심사 🤖** → AI가 주제, 창의성, 표현력, 완성도를 채점해요.
6. **3위 발표 → 2위 발표 → 1위 발표!(꽃가루) → 전체 순위.** 스페이스바나 → 키로도 넘길 수 있어요.
7. 다시 하려면 **새 게임 🔄**을 누르면 돼요. 같은 QR을 그대로 쓸 수 있어요.

### 미리 알아두면 좋은 것

- **리허설 강력 추천**: 전날 ⚙️ → 테스트 참가자 추가 → 시작 → 마감까지 한 번 돌려보면 Gemini 키와 Firebase를 함께 점검할 수 있어요. 끝나면 "게임 초기화"를 눌러요.
- **점수 계산**: 최종 점수 = AI 평균 × 70% + (내 좋아요 ÷ 최다 좋아요 × 100) × 30%. 비율은 설정에서 바꿀 수 있고, 좋아요가 하나도 없으면 AI 점수만 반영돼요.
- **AI가 실패하면**: 진행자 화면에 [다시 시도]와 [좋아요 수로만 순위 정하기] 버튼이 떠서 행사가 멈추지 않아요.
- **미제출자**: 마감할 때 제출하지 않은 사람은 심사에서 빠져요(확인창이 떠요).
- **새로고침해도 괜찮아요**: 진행자 화면과 참가자 화면 모두 진행 상태가 이어져요. 그리던 그림도 휴대폰에 남아 있어요.
- **회사 Wi-Fi**가 외부 사이트를 막으면 참가자는 LTE/5G로 접속하라고 안내하세요.

### 행사 후 정리

- Firebase 콘솔 → Realtime Database → 데이터 탭에서 `rooms`를 삭제하면 그림과 이름이 지워져요.
- 이후 쓸 일이 없으면 규칙의 `"rooms"` 부분을 `".read": false, ".write": false`로 바꿔 잠가두세요.
